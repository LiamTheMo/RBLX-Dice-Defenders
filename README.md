# RBLX-Dice-Defenders

A planned Roblox co-operative dice-merging defense game with a 100-wave world campaign, solo/duo play, Infinite mode, dice collecting and upgrading, and server-verified leaderboards.

**Project status:** preproduction/design only. No playable implementation or assets are included yet. Numerical balance values and future features in the documents are proposals pending playtesting.

## Design documentation

- [Game Design Document](docs/GDD.md) — core loop, boards, co-op, stage, bosses, currencies, systems, launch scope and technical architecture.
- [Dice Catalog](docs/DICE_CATALOG.md) — initial 19-dice roster, base statistics, individual mechanics, synergies and unlock paths.
- [Balancing & Economy](docs/BALANCING.md) — wave exponential scaling, Infinite kill pressure, player count multipliers, boss cadence, rewards, crafting, chest probabilities, anti-exploit and leaderboards.
- [Art & Modeling Production](docs/ART_PIPELINE.md) — mandatory ChatGPT-generated UI assets and one complete exploded 3D reference sheet for **every** new dice.
- [Future Updates Roadmap](docs/FUTURE_UPDATES.md) — Update 1 new world and special dice; Update 2 Rift Expeditions PvE; Update 3 competitive PvP; additional future content updates.
